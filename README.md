# F1 Lap Vault v4

Mobile-first GitHub-Pages-Webapp für Rundenzeiten und Setups.

## v4 neu
- Oberfläche eng am bereitgestellten Lap-Vault-Mockup orientiert
- Streckenwahl als Dropdown
- Streckenkarte direkt im Header, bei jeder Auswahl aktualisiert
- große Bestzeit-/Delta-Karte
- Reifenwahl wie im Mockup
- Setup-Navigation in Aerodynamik / Fahrwerk / Bremsen / Reifen
- Werte als In-Game-artige Slider
- lokale Speicherung per `localStorage`
- kein Backend nötig

## GitHub Pages
1. Dateien in ein Repository hochladen.
2. **Settings → Pages** öffnen.
3. **Deploy from a branch** wählen.
4. Branch `main` und Ordner `/ (root)` wählen.

Das Projekt ist ein unabhängiges Community-Tool und verwendet keine offiziellen EA-, Codemasters- oder F1-Spiel-Assets.
